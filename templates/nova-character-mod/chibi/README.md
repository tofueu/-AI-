# NOVA chibi 開放角色 MOD 骨架範本 v1

這個資料夾是**通用骨架規格**，不是已經完成的官方人物分層圖；要呈現角色，請畫師自行準備 `parts/*.png`，採 RGBA 透明背景。

## 快速操作
1. 在此資料夾新增 `parts/`，各檔名稱依 rig.json 的 parts.file。
2. 以 256×256 PNG 當起點，**每張圖的 (128,128) 像素是對應骨骼的旋轉基準點**。如要改尺寸，必須同步修改 pivot。[畫師可換尺寸]
3. 按頭、肩、肘、手腕、膝、踝分層；手臂必須至少切成上臂／前臂／手，否則無法真的彎手肘。
4. Windows Chrome/Edge 開 AI Workbench，NOVA 浮窗按「匯入角色資料夾」，選擇本資料夾。
5. 動作使用同一套骨架 `idle/typing/walk/run/wave/jump/sit/sleep/...`，200ms 混合，不需要每個 MOD 重畫 12 張工作圖。
6. 匯入動作與素材**只在本機瀏覽器記憶體**；不會自動上傳任何人畫的圖到 Git。之後正式安裝／ZIP 部署需另做。

注意：官方原始人物圖是整張扁平圖，不能直接當這個範本的多層 PNG；必須實際分割繪製遮擋部位。缺素材時匯入器會報錯，並保留既有官方逐格動畫。
