# NOVA Q 版暫時核准與整合驗收界線 (2026-10-31)

## 使用者決策
使用者 **暫時通過 Q 版**，允許先套用到現有 AI Workbench。此決策不是成熟版核准，也不是正式關節動畫品質驗收。應維持既有完整角色外觀，並持續改良中間動作關節。

## 此分支目前已有的功能
- Web 工作台 `public/index.html` 以 `mountNovaPet` 啟動 NOVA；`public/nova-official-player.js` 預設 `chibi`，每約 3.5 秒從真實 `/api/tasks` 更新狀態；圖片只從可驗證的官方本機 MOD manifest 載入。
- `nova-official-installer.js` 復原 Git 備份的 v0.2 官方圖與逐格動畫；官方 Q 版仍是幀動畫，不是已綁定關節的可換裝 Live2D。
- `public/nova-rig-runtime.js` 與 `templates/nova-character-mod/chibi/rig.json` 提供獨立的社群分層骨架、動作、PSD/PNG 角色匯入。

## 新版 Q 圖驗收條件（不得假稱已完成）
1. 以使用者 **下午 14:20、14:40** 認可的各動作獨立分鏡為視覺基準，**一種動作一張分鏡**；每格只有一個完整 Q 版人物，小貓、整段髮絲、帽兜、蝴蝶結、鞋子、手部、配件都不能被截斷或跑到隔壁格。
2. 相鄰幀必須補真正過渡姿勢，尤其肩、肘、腕、手指、頭髮、帽兜與裙擺，而非重複相同姿勢湊格數。要以至少兩張相鄰分鏡手部角度比對並檢驗連續性。
3. 各動作完成後再產生各自 GIF、透明逐幀 PNG 與 manifest，然後才更新官方 runtime ZIP/checksum。不要直接將帶有格線的分鏡大圖當作透明角色動畫。
4. 為畫師提供繪製各個部位及多角度的 PSD 模板，包含正/側/背可替換圖、關節 pivot、遮擋順序、實際動作 clip；上傳畫師 MOD 後應能沿用相同動作。
5. 對同一套角色分別驗證 Web 動畫與 Windows 桌寵：真實工作台 running/queued/error/done 映射、逐格切換、不剪裁、固定腳底基準、手掌及頭髮不跳位。

## 發行界線
**Q 版作為暫准 preview 開放使用**；但新版分鏡的逐幀切割、新增真正中間姿勢、導入官方角色關節和 Windows 實機驗收仍未確認。成熟版保持原有狀態並繼續開發。禁止宣稱已完成所有 GIF、完成關節模型或測試通過，除非附有可核查的圖檔、執行記錄與 commits。
